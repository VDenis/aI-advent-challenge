# План: Голосовой ввод для Personal Chat

## Цель
Голосовая команда → распознавание в текст (Whisper) → отправка в GigaChat → текстовый ответ.

## Архитектура

```
[Микрофон] → sounddevice (запись WAV) → Whisper (STT) → текст
     ↓
PersonalChatCLI.send_message(текст) → GigaChat → ответ на экране
```

## Шаги реализации

### 1. Модуль `voice.py`
- Класс `VoiceRecorder` — запись аудио с микрофона через `sounddevice`
  - `record(duration_sec=5)` → numpy array
  - Сохранение во временный WAV-файл
- Класс `SpeechRecognizer` — распознавание через OpenAI Whisper
  - Загрузка модели `base` (140MB, хорошее качество для русского)
  - `recognize(audio_path) → str` — возвращает распознанный текст
- Функция `voice_input() → str` — объединяет запись + распознавание

### 2. Интеграция в `main.py`
- Горячая клавиша: **Enter без текста** → запуск записи голоса
- Показ статуса: «🎤 Говорите... (5 сек)» → «⏳ Распознаю...» → «📝 Распознано: <текст>»
- Распознанный текст отправляется в `send_message()` как обычный ввод
- Команда `/voice` — переключение on/off голосового режима

### 3. Зависимости (добавить в `requirements.txt`)
```
openai-whisper>=20231117
sounddevice>=0.4.6
numpy>=1.24.0
```

### 4. Тестирование
- Запрос «посчитай 2 плюс 2» — проверка распознавания + ответ
- Запрос «дай определение рекурсии» — проверка длинного ответа
- Запрос «скажи анекдот» — проверка генерации
- Скрипт `test_voice.py` для автономного теста STT

## Параметры
- Модель Whisper: `base` (по умолчанию, можно сменить на `small`/`medium`)
- Длительность записи: 5 секунд (по умолчанию)
- Частота дискретизации: 16000 Hz (оптимально для Whisper)
- Язык: `ru` (принудительно, для лучшего качества)
