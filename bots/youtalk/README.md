# YouTalk: YouTube RAG Chat-Bot

Минималистичный консольный чат-бот с архитектурой RAG (Retrieval-Augmented Generation), который умеет индексировать локальные документы и субтитры YouTube видео в реальном времени.

## Особенности
- **Динамический RAG**: Просто вставьте ссылку на YouTube видео в чат, и бот мгновенно проиндексирует его субтитры.
- **Память диалога**: Поддерживает контекст беседы и умеет переформулировать уточняющие вопросы в самостоятельные запросы.
- **Прозрачность**: Всегда выводит источники (названия файлов или заголовки видео) и конкретные фрагменты текста, на основе которых был дан ответ.
- **Online-first**: Использует Hugging Face Inference API для LLM и эмбеддингов (не требует мощного GPU).

## Технологический стек
- **LLM**: Llama-3.1-8B-Instruct (через Hugging Face Router API).
- **Embeddings**: paraphrase-multilingual-MiniLM-L12-v2 (через Hugging Face).
- **Vector Store**: FAISS (локальное хранение индекса).
- **Framework**: LangChain.
- **YouTube**: youtube-transcript-api, pytube.

## Быстрый старт

### 1. Требования
- Python 3.9+
- Активный `HF_TOKEN` (токен Hugging Face с правами на чтение).

### 2. Установка
```bash
cd bots/youtalk
pip install -r requirements.txt
```

### 3. Настройка
Создайте файл `.env` в папке `bots/youtalk/`:
```env
HF_TOKEN=hf_your_token_here
```

### 4. Запуск
```bash
python main.py
```

## Как пользоваться
1. **Чат**: Просто пишите вопросы.
2. **YouTube**: Отправьте ссылку на видео (например, `https://www.youtube.com/watch?v=...`), и бот добавит его содержимое в свою память.
3. **Локальные файлы**: Положите `.txt` или `.md` файлы в папку `./docs/`, и они будут проиндексированы при запуске.
